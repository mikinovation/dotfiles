# PRD: 端末多重化ツールの導入

所有者が、複数のエージェントを同時に走らせながら、どれに手を入れるべきかを一画面で判断できるようにするための要求と受入条件を定める。

- 読者: 開発者

この PRD の用語は次の意味で使う。

- エージェント: 指示を受けてコードを書き換える AI のプログラムのうち、端末の中で動かすもの。
- 端末多重化ツール: 一つの端末画面を分割し、複数の作業を同時に表示して切り替えるツール。
- 「すべて」「最小限」: PRD 0001「開発環境の導入」で定める導入範囲。

## 問題

エージェントを複数同時に走らせると、どれが入力待ちでどれが作業中かを一度に見られない。
所有者は端末を順に切り替えて状態を確かめることになり、手を入れるべきエージェントに気付くのが遅れる。
扱うプロジェクトが複数あると、プロジェクトごとの端末の行き来も増える。
また、エディターで開いているコードや指示をエージェントへ渡すたびに、手作業でのコピーと貼り付けが挟まる。

## 対象となる利用者

リポジトリの所有者本人だけを対象とする。

## 提供する価値

所有者は、同時に走るエージェントのうちどれに手を入れるべきかをすぐ判断でき、端末を探し回らずに済む。
エディターを離れずに、エージェントへ指示を渡し、新しいエージェントを立ち上げられる。
エージェントの監視だけでなく、通常のシェル作業も同じ画面で行う。
この機能は「すべて」を導入した場合にだけ使える。

## 要求と受入条件

各要求と、その要求を受け入れる条件は次のとおり。

| # | 要求 | 受入条件 |
|---|---|---|
| 1 | 複数のエージェントを同時に走らせ、一画面で状態を把握できる | 複数のエージェントが動いている状態で、切り替えずに各々の状態が分かる |
| 2 | 注目するエージェントを全画面に広げて詳しく見られる | 1つの操作で全画面表示と元の配置を行き来できる |
| 3 | 一覧を出すサイドバーを開閉できる | 1つの操作で開閉でき、畳むと画面を占有しない |
| 4 | 手を入れるべきエージェントが一覧の上位に来る | 一覧が優先度の順で並ぶ |
| 5 | プロジェクト単位でタブをまとめ、まとまりを切り替えられる | まとまりを新規作成し、前後に切り替えられる |
| 6 | タブを増やし、前後に切り替えられる | タブを新規作成し、前後に切り替えられる |
| 7 | 画面を縦横に分割し、隣の領域へ移動できる | 縦横に分割でき、上下左右の隣へ移動できる |
| 8 | 分割、移動、タブの操作を、一般的な端末多重化ツールと同じ指使いで行える | これらの操作のキーが、一般的な端末多重化ツールの割り当てと一致する |
| 9 | マウスでも操作できる | マウスの操作を受け付ける |
| 10 | 過去の出力を一定量さかのぼって読める | 画面から流れた出力を、上限まで戻って読める |
| 11 | エディターから、選択範囲、現在行、ファイルパス、自由入力のテキストを、動いているエージェントへ送れる | 4種類のいずれも、エディターから送信まで完了する |
| 12 | 送り先のエージェントが複数あるときだけ、送り先を選べる | 1つのときは選択を求めずに送る。複数のときは選ばせる |
| 13 | エディターから、編集中のファイルの場所で新しいエージェントを立ち上げられる | 編集中のファイルの場所を作業場所としてエージェントが起動し、隣の領域に並ぶ |
| 14 | 立ち上げるエージェントに名前を付けられる | 起動時に名前を尋ね、編集中の場所の名前が既定値として入る |
| 15 | エディターから、プロジェクトのまとまりを一覧して切り替えられる | 動いているまとまりを一覧でき、選んだものへ切り替わる |
| 16 | 送れない状態のときは、その理由が分かり、何も起きない | 下記の異常時の受入条件をすべて満たす |
| 17 | 操作の成否がエディター上で分かる | 成功時と失敗時で、それぞれ区別できる通知が出る |

要求15では、まとまりが1つのときは選択を求めない。

要求16と要求17の異常時の受入条件は次のとおり。

- 端末多重化ツールの外で操作すると、理由が示され、何も起きない。
- 端末多重化ツールが使えない環境で操作すると、理由が示され、何も起きない。
- 送り先のエージェントが1つも無いとき、理由が示され、何も送られない。
- 送る内容が空のとき、理由が示され、何も送られない。
- 送り先の選択や名前の入力を取り消すと、何も起きない。
- 送信、起動、切り替えに失敗したとき、成功の通知は出ない。

## 対象外

- 「最小限」の導入範囲でこの機能を提供すること。
- 端末を閉じたあとの画面構成の復元。
- シェルの起動時に自動で立ち上げること。

## 成功条件

「すべて」を導入したあと、手作業で設定せずに、複数のエージェントを同時に走らせて監視でき、エディターを離れずに指示を渡せる。
数値目標は設けない。
